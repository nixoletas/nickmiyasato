Cerimônia militar tem protocolo. Convidados não são uma lista plana — são ordenados por antiguidade, separados por categoria, e um subconjunto específico é lido em voz alta durante a própria cerimônia. É essa última parte que impede isso de ser só uma planilha: alguém precisa subir com uma folha contendo exatamente os nomes certos na ordem certa.

O app é um CRUD de convidados com nome, função e categoria. Ordena por antiguidade, controla quem confirmou, permite marcar as autoridades a serem anunciadas, busca por nome e gera o PDF de impressão que vai para o púlpito.

EJS renderizado no servidor foi a escolha certa para algo cuja saída final é um pedaço de papel. Sem build, sem framework de cliente — a página é gerada onde os dados já estão.
